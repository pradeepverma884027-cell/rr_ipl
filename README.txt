SupeRR Selector public dashboard package

Contents: index.html only. This is a self-contained, static dashboard with methodology, eligibility rules, corrected Top 10 aggregate statistics and comparison controls. It contains no raw ball-by-ball dataset or full player database.

To publish: upload this folder to a static host such as GitHub Pages, Netlify Drop, or Cloudflare Pages. It has no build step or external JavaScript dependencies.
